# Harmonic vs Cycloidal Drive – 토크, 백래시 및 마모 테스트

이 글에서는 3D 프린팅된 조화 드라이브와 3D 프린팅된 사이클로이드 드라이브 중 어느 쪽이 더 나은지 살펴보겠습니다. 여기 제가 만든 두 개의 기어박스가 있는데, 크기와 감량 비율이 25:1입니다. 여러 카테고리에서 비교하고, 효율이나 토크 출력을 측정하며, 정확도나 백래시도 측정하고, 내구성을 확인할 것입니다.

## 동작 원리 개요

이미 제 채널에 고조파 구동과 사이클로이드 구동이 무엇이고 어떻게 작동하는지, 그리고 설계 방법을 자세히 설명하는 전용 영상이 있으니, 더 자세한 내용은 그 튜토리얼들을 확인해 보시길 권합니다.

간단히 말해, 하모닉 드라이브와 사이클로이드 드라이브 모두 독특한 유형의 기어박스 또는 감속기로, 매우 높은 감속비를 제공하면서도 컴팩트하면서도 견고한 설계를 제공합니다. 작동 원리는 비슷한데, 입력축이 비규칙 모양 부품을 구동하고, 조화 구동 방식은 파동 발생기, 사이클로이드 구동 방식은 이심 베어링을 구동합니다.

각 기어박스가 가진 독특한 부품들의 도움으로 매우 작은 공간에서 훨씬 낮은 속도로 출력을 낼 수 있습니다.

### 감축비

- **고조파 구동**의 감축비는 항상 플렉스 스플라인 이빨 수의 절반입니다. 25:1 감축비를 원한다면, 플렉스 스플라인에는 50개의 이빨, 원형 스플라인에는 52개의 이빨이 필요합니다.
- **사이클로이드 구동**의 감축 비율은 항상 링 기어의 핀 수보다 1개 적으며, 25:1 감축 비율을 위해서는 링 기어에 26개의 핀이 필요합니다.

## 설계

두 기어박스를 같은 크기와 감축 비율(25:1)로 만들어서 쉽게 비교할 수 있게 하는 것이 목표였습니다. 기어박스를 최대한 작게 만들고 싶었습니다.

### 사이클로이드 드라이브 설계

첫 입력 매개변수는 사이클로이드 구동 링 기어용 롤러에 장착된 핀 크기였습니다. 6mm 핀을 가지고 있었는데, 더 부드러운 작동을 위해 8mm 부싱에 장착할 계획이었습니다. 8mm 직경의 26개 롤러와 부싱으로 스케치를 그렸습니다.

이 두 입력 매개변수에 따라 링 기어 피치 직경의 최소 크기를 정의할 수 있으며, 이는 결국 기어박스 크기를 결정합니다. 하우징 직경은 26개 부싱 전부를 모두 수용하고 전체 기어박스를 조립할 수 있는 M4 볼트를 넣을 수 있는 벽 두께를 확보하기 위해 95mm여야 했습니다.

사이클로이드 디스크 형태를 생성하려면 한 가지 추가 입력 매개변수가 필요한데, 바로 **이심도 값(Eccentricity)**으로, 핀 직경의 절반보다 작아야 합니다.

#### 사이클로이드 디스크 매개변수 방정식 (Omar Younis)

```
N  - Number of rollers
Rr - Radius of the roller
R  - Radius of the rollers PCD (Pitch Circle Diameter)
E  - Eccentricity - offset from input shaft to a cycloidal disk

x = (R*cos(t)) - (Rr*cos(t + arctan(sin((1-N)t) / (R/(E*N) - cos((1-N)t))))) - (E*cos(N*t))
y = (-R*sin(t)) + (Rr*sin(t + arctan(sin((1-N)t) / (R/(E*N) - cos((1-N)t))))) + (E*sin(N*t))
```

**적용 예 (25:1, N=26):**

| 파라미터 | 값  |
|----------|-----|
| N        | 26  |
| Rr       | 3   |
| R        | 36  |
| E        | 0.75 |

```
x = (36*cos(t)) - (3*cos(t + arctan(sin((1-26)t) / (36/(0.75*26) - cos((1-26)t))))) - (0.75*cos(26*t))
y = (-36*sin(t)) + (3*sin(t + arctan(sin((1-26)t) / (36/(0.75*26) - cos((1-26)t))))) + (0.75*sin(26*t))
```

> "t" 파라미터는 0부터 2π까지의 값을 사용해야 합니다. 다만, 곡선을 생성하려면 2π보다 약간 작은 값을 사용해야 한다는 점을 유의해야 합니다. 이렇게 하면 약간의 간격이 있는 곡선이 생성되고, 스플라인으로 쉽게 연결할 수 있습니다.

프로파일을 압출하고, 이심 베어링과 출력 핀을 위한 구멍을 만들 수 있습니다. 출력 구멍들의 직경은 `핀 롤러 직경 + 편심도의 2배`와 같습니다. 이 경우 `8 + 0.75*2 = 9.5mm` 직경입니다.

### 고조파 구동 설계

두 기어박스 모두 같은 크기로 만드는 것이 아이디어였고, 기어박스 직경은 맞출 수 있었지만 플렉스 스플라인을 수용하기 위해 길이가 조금 더 길어져야 했습니다.

플렉스 스플라인은 매우 독특한 부품으로, 열린 쪽은 유연해야 하지만 하단이나 출력은 강해야 합니다. 사이클로이드 기어박스의 길이 치수에 맞추기 위해 컵을 짧게 만들려 하면, PLA 소재를 사용하고 있어 유연성이 부족하고 벽이 쉽게 부서질 수 있기 때문에 제대로 작동하지 않습니다.

**플렉스 스플라인 설계:**
- SOLIDWORKS 툴박스 사용, 1.5 모듈
- 50개 이빨 스퍼 기어 생성
- 컵 벽: 1.25mm, 컵 전체 길이: 30mm

**원형 스플라인 설계:**
- SOLIDWORKS 툴박스 사용
- 52개 이빨 내부 스퍼 기어
- 기어 내부에 0.1mm 간격 (3D 프린팅 부품 공차 고려)

**파동 발생기:**
- 플렉스 스플라인 내벽 직경보다 장축이 3.2mm 크고, 단축이 3.2mm 작은 타원
- 장축 양쪽에 베어링 3개 배치

부품의 정확한 치수를 얻기 위해서는 슬라이싱 소프트웨어에 적절한 설정이 필요합니다.

**중요 설정:**
- **수평 확장 (Horizontal Expansion):** 0.02mm
- **구멍 수평 확장 (Hole Horizontal Expansion):** 0.04mm

3D 프린터에서 어떤 값이 가장 좋은 결과를 낼지 테스트 출력을 해보는 것이 좋습니다.

- 플렉스 스플라인과 사이클로이드 디스크: 수평 확장 `–0.01 ~ –0.02mm`
  - 이 부품들은 움직일 수 있도록 클리어런스 핏이 있어야 합니다.

## 문제 해결

사이클로이드 디스크와 비교했을 때, 고조파 구동장치의 움직임이 그리 부드럽지 않았습니다. 원인은 다음과 같습니다:

### 1. 플렉스 스플라인 파손
- 컵 벽이 너무 얇아 변형을 견디지 못함
- 컵이 너무 작아 탄성 변형 수용이 어려움
- 다른 필라멘트 + 벽 두께 3겹 시도했으나 실패

### 2. 파동 발생기 접촉 불량
- 상단 베어링이 플렉스 스플라인에 닿지 않음
- → 파동 발생기를 단일 베어링으로 수정하여 개선

### 3. 내부 표면 불균일
- 3D 프린팅 시 벽선이 하나만 있어 표면이 거침
- → 벽 두께 4겹(1.6mm)으로 증가시켜 표면 개선

### 4. Z 이음매(Z-Seam) 문제
- "사용자 지정" 정렬로 인해 돌출부 발생
- → "랜덤"으로 설정하여 표면과 움직임 개선

## 하모닉 vs 사이클로이드 – 비교

### 백래시

| 항목 | 하모닉 드라이브 | 사이클로이드 드라이브 |
|------|:--------------:|:------------------:|
| 반복성 | 우수 | 우수 |
| 양방향 힘 (15cm 거리) | 8mm 백래시 | 6.5mm 백래시 |
| 정지 상태 작은 힘 | 우수 (역류 없음) | 약 2mm 유격 |
| 정지 상태 큰 힘 | 최대 7mm 유격 | 약 5.5mm 유격 |

### 토크

| 테스트 | 하모닉 드라이브 | 사이클로이드 드라이브 |
|--------|:--------------:|:------------------:|
| NEMA17 최대 토크 | 4.8Nm (32N @ 15cm) | 4.8Nm (32N @ 15cm) |
| 효율 | ~65% | ~65% |
| NEMA23 최대 토크 | 즉시 고장 | 21.5Nm (43N @ 0.5m) |
| 토크 증가율 | - | 7배 (3Nm → 21.5Nm) |

사이클로이드 드라이브는 16배 토크 증가 (0.3Nm → 4.8Nm, 효율 65%).

NEMA23 테스트:
- 사이클로이드: 15cm 막대 80N(12Nm)에서 파손 → 합판 막대로 교체 후 0.5m @ 30N(15Nm)에서 디스크 파손 시작 → 보강 후 0.5m @ 43N(21.5Nm)까지 도달
- 하모닉: NEMA23 부하에서 즉시 고장

### 내구성

사이클로이달 구동은 고조파 구동보다 훨씬 더 오래 지속될 수 있습니다. PLA 플렉스 스플라인은 밤새 한 자세로 놓여 있어도 소성 변형이 생길 정도로 내구성이 취약합니다.

## 결론

**3D 프린팅된 하모닉 드라이브 vs 3D 프린팅된 사이클로이드 드라이브 – 어느 쪽이 더 나은가?**

정답은 **"상황에 따라 다릅니다."**

### 사이클로이드 드라이브의 장점
- 더 큰 토크 제공
- 더 신뢰할 수 있으며 내구성 우수
- 디스크 정밀도 개선을 통한 백래시 개선 여지 있음

### 하모닉 드라이브의 장점
- 백래시 측면에서 확실히 더 나을 수 있음
- NEMA17 부하에서는 사이클로이드와 유사한 성능

### 한계점
- **하모닉 드라이브:** 플렉스 스플라인의 내구성 문제. 개선하려면 설계가 더 크고 길어져야 하며, 이는 컴팩트함을 희생해야 함.
- **사이클로이드 드라이브:** 고하중에서 디스크 변형 및 파손 가능성

> PLA 이외의 다른 3D 프린팅 재료를 사용하면 두 드라이브 모두 성능이 개선될 수 있습니다.
